# 错误处理规范

本文档定义前端项目错误处理的最佳实践,包括全局错误捕获、异步错误处理、错误边界、错误上报等机制。

---

## 全局错误捕获机制

### Vue 应用全局错误处理

**核心配置:**
- `app.config.errorHandler`: 处理 Vue 组件错误
- `app.config.warnHandler`: 处理 Vue 警告(仅开发环境)

**处理要点:**
- 捕获错误并记录日志
- 上报错误到监控系统
- 显示用户友好提示

### JavaScript 全局错误捕获

**关键机制:**
- `window.onerror`: 捕获未处理的 JavaScript 错误
- `unhandledrejection`: 捕获未处理的 Promise 拒绝
- 资源加载错误捕获(使用捕获阶段)

---

## 异步错误处理规范

### Async/Await 错误处理

**核心模式:**
- 使用 try-catch 捕获错误
- 错误包装器(返回 [data, error] 元组)
- 带重试机制的异步操作

### API 请求错误处理

**拦截器配置:**
- 请求拦截器: 添加认证 token、CSRF token
- 响应拦截器: 处理 HTTP 错误状态码、业务逻辑错误

**状态码处理:**
- 400: 请求参数错误
- 401: 未授权,跳转登录页
- 403: 拒绝访问
- 404: 资源不存在
- 500: 服务器内部错误

## Vue 错误边界实现

### 错误边界组件

**核心功能:**
- 使用 `onErrorCaptured` 捕获子组件错误
- 提供错误回退 UI
- 暴露重置方法

**使用场景:**
- 包裹关键组件
- 路由级别错误边界
- 组件级别错误隔离

## 错误上报机制

### 错误上报服务

**核心功能:**
- 错误队列管理
- 批量上报(减少请求次数)
- 采样率控制
- 环境信息添加

**上报时机:**
- 达到队列最大值时立即上报
- 定时批量上报
- 页面关闭前上报(beforeunload)

### 错误分类和过滤

**忽略策略:**
- ResizeObserver 错误
- Network request failed
- Script error
- Non-Error promise rejection

**错误分级:**
- critical: 致命错误
- error: 普通错误
- warning: 警告级别

## 错误日志规范

### 日志级别

**级别定义:**
- `debug`: 调试信息(仅开发环境)
- `info`: 常规信息
- `warn`: 警告信息
- `error`: 错误信息

### 日志配置

**核心要点:**
- 根据环境设置日志级别
- 开发环境启用控制台输出

- 敏感信息脱敏

## 错误类型定义

### 错误接口定义

**核心字段:**
- type: 错误类型
- message: 错误消息
- stack: 错误堆栈
- timestamp: 时间戳
- userAgent: 用户代理
- url: 页面 URL

### 自定义错误类

**常见错误类:**
- `AppError`: 应用错误
- `NetworkError`: 网络错误
- `ValidationError`: 验证错误
- `ApiError`: API 错误

## 错误处理最佳实践

### 核心原则

1. **不吞掉错误**: 至少记录日志并上报
2. **不使用空 catch**: 至少记录错误
3. **提供具体错误提示**: 避免笼统的"操作失败"
4. **处理异步错误**: 使用 try-catch 或 .catch()
5. **不暴露敏感信息**: 生产环境只显示友好消息

### 错误处理流程

```
捕获错误
  ↓
记录日志
  ↓
上报错误
  ↓
显示友好提示
```
