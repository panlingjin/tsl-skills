# 安全规范

本文档定义前端项目的安全防护策略、敏感数据处理规范、接口安全规范和权限控制实现指南。前端控制不能替代服务端认证、授权、输入验证和数据保护。

---

## XSS 防护策略

### XSS 攻击类型

| 类型 | 特点 | 危害等级 |
|------|------|---------|
| 反射型 XSS | URL 参数注入 | 高 |
| 存储型 XSS | 数据库存储恶意代码 | 极高 |
| DOM 型 XSS | DOM 操作注入 | 中 |

### XSS 防护措施

**输入与输出处理:**
- 普通文本使用 Vue 文本插值执行 HTML 转义
- 按输出上下文编码，不依赖过滤少量危险字符
- 验证 URL 协议，禁止 javascript: 等危险协议
- 富文本使用经过维护的白名单净化器

**CSP 配置:**
- default-src 'self'
- script-src 'self' 'nonce-<服务端随机值>'
- style-src 'self' 'nonce-<服务端随机值>'
- img-src 'self' data: https:
- frame-src 'none'
- object-src 'none'

nonce 必须由服务端为每次响应随机生成，不能把固定占位值用于生产环境，也不把 `'unsafe-inline'` 作为推荐默认值。

**Vue 中的 XSS 防护:**
- 避免直接使用 v-html
- 使用文本绑定 {{ }}
- 必须使用 v-html 时进行白名单净化

## CSRF 防护策略

### CSRF 防护措施

**Token 验证机制:**
- 服务端生成随机 CSRF Token 并与用户会话绑定
- 前端从服务端约定的位置读取 Token
- 状态变更请求按服务端约定携带 Token
- 服务端验证 Token 和请求来源

**SameSite Cookie 设置:**
- Strict: 完全禁止跨站 Cookie
- Lax: 允许 GET 请求携带跨站 Cookie
- None: 允许跨站携带，必须同时设置 Secure

**Cookie 安全属性:**
- 认证 Cookie 按部署场景设置 Secure、HttpOnly 和 SameSite
- 不在 sessionStorage 中复制会话标识或认证 Cookie
- 不把 X-Requested-With 当作独立的 CSRF 防护

## 敏感数据处理规范

### 数据分类标准

| 分类 | 数据类型 | 处理规范 |
|------|---------|---------|
| 高敏感 | 密码、支付信息、身份证号 | 禁止前端存储,加密传输 |
| 中敏感 | 手机号、邮箱、地址 | 脱敏显示,加密传输 |
| 低敏感 | 用户名、昵称、头像 | 正常处理,避免明文存储 |

### 数据脱敏处理

**脱敏规则:**
- 手机号: 保留前3后4,中间4位替换为*
- 邮箱: 保留前2位和域名,中间替换为*
- 身份证号: 保留前6后4,中间8位替换为*
- 银行卡号: 保留前4后4,中间替换为*
- 姓名: 保留首尾,中间替换为*

### 数据加密传输

**加密方式:**
- 生产环境使用 HTTPS 保护传输
- 密码哈希、密钥管理和签名验证由受控服务端完成
- 不使用 MD5 或普通 SHA 哈希处理密码

### 本地存储安全

**安全策略:**
- 使用 sessionStorage 存储临时数据
- localStorage、sessionStorage 和 IndexedDB 不存储密码、会话标识、私钥、支付信息等敏感数据
- 不把“前端加密后存储”作为敏感数据的安全替代方案
- 定期清理存储数据

## 接口安全规范

### HTTPS 强制使用

**强制 HTTPS:**
- 由服务端或边缘层将非 HTTPS 请求重定向到 HTTPS
- 检查协议安全性
- 配置 HSTS 和必要的安全响应头

### 请求签名验证

**签名机制:**
- 不在前端保存长期共享密钥
- 不使用内置静态密钥生成服务端信任的签名
- 确需签名时采用服务端提供的短期机制并明确威胁模型
- 签名与权限仍由服务端验证

### 请求超时与重试

**安全配置:**
- 设置合理的超时时间
- 仅在明确需要时跨域携带 Cookie(withCredentials)
- Cookie 认证请求使用服务端 CSRF 防护
- 只重试明确可重试且幂等的请求，并限制次数

## 权限控制实现指南

路由、组件和按钮权限只负责前端体验；服务端必须对每个受保护请求和具体资源执行授权检查。

### 前端权限架构

**权限控制层级:**
- 用户认证(Authentication)
- 角色分配(Role Assignment)
- 权限验证(Permission Check)
- 资源访问(Resource Access)

### 路由权限控制

**路由守卫:**
- 检查认证状态
- 检查角色权限
- 检查权限点
- 无权限跳转 403 页面

### 组件权限控制

**权限组件:**
- 检查权限点
- 检查角色
- 无权限显示占位内容

### API 权限控制

**拦截器:**
- 请求拦截器: 添加认证 token
- 响应拦截器: 处理 401/403 错误
- 服务端: 验证身份并执行资源级授权

### 按钮级权限控制

**权限检查:**
- 检查权限点
- 动态显示/隐藏按钮
