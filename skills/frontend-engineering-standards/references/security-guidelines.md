# 安全规范

本文档定义前端项目的安全防护策略、敏感数据处理规范、接口安全规范和权限控制实现指南。

---

## XSS 防护策略

### XSS 攻击类型

| 类型 | 特点 | 危害等级 |
|------|------|---------|
| 反射型 XSS | URL 参数注入 | 高 |
| 存储型 XSS | 数据库存储恶意代码 | 极高 |
| DOM 型 XSS | DOM 操作注入 | 中 |

### XSS 防护措施

**输入过滤:**
- HTML 实体编码
- 过滤危险字符(script 标签、on* 属性)
- URL 安全性验证
- 富文本内容过滤

**CSP 配置:**
- default-src 'self'
- script-src 'self' 'unsafe-inline'
- style-src 'self' 'unsafe-inline'
- img-src 'self' data: https:
- frame-src 'none'
- object-src 'none'

**Vue 中的 XSS 防护:**
- 避免直接使用 v-html
- 使用文本绑定 {{ }}
- 必须使用 v-html 时进行安全过滤

## CSRF 防护策略

### CSRF 防护措施

**Token 验证机制:**
- 生成随机 CSRF Token
- 存储在 sessionStorage
- 非 GET 请求添加到请求头
- 后端验证 Token

**SameSite Cookie 设置:**
- Strict: 完全禁止跨站 Cookie
- Lax: 允许 GET 请求携带跨站 Cookie
- None: 无限制(不推荐)

**双重 Cookie 验证:**
- Cookie 存储 Token
- Session 存储 Token
- 验证两者一致性

## 敏感数据处理规范

### 数据分类标准

| 分类 | 数据类型 | 处理规范 |
|------|---------|---------|
| 高敏感 | 密码、支付信息、身份证号 | 禁止前端存储,加密传输 |
| 中敏感 | 手机号、邮箱、地址 | 脱敏显示,加密传输 |
| 低敏感 | 用户名、昵称、头像 | 正常处理,避免明文存储 |

### 数据脱敏处理

**脱敏规则:**
- 手机号: 保留前3后4,中间4位替换为*
- 邮箱: 保留前2位和域名,中间替换为*
- 身份证号: 保留前6后4,中间8位替换为*
- 银行卡号: 保留前4后4,中间替换为*
- 姓名: 保留首尾,中间替换为*

### 数据加密传输

**加密方式:**
- AES 加密(可逆)
- MD5/SHA256 哈希(不可逆)
- RSA 加密(公钥加密)

### 本地存储安全

**安全策略:**
- 使用 sessionStorage 存储临时数据
- 敏感数据加密后存储
- 禁止存储密码等高敏感信息
- 定期清理存储数据

## 接口安全规范

### HTTPS 强制使用

**强制 HTTPS:**
- 非 HTTPS 请求重定向到 HTTPS
- 检查协议安全性
- 升级不安全请求

### 请求签名验证

**签名机制:**
- 参数排序
- 添加时间戳和随机数
- 生成签名(使用密钥)
- 请求头携带签名信息

### 请求超时与重试

**安全配置:**
- 设置合理的超时时间
- 跨域携带 Cookie(withCredentials)
- 防止 CSRF(X-Requested-With)
- 限制重试次数

## 权限控制实现指南

### 前端权限架构

**权限控制层级:**
- 用户认证(Authentication)
- 角色分配(Role Assignment)
- 权限验证(Permission Check)
- 资源访问(Resource Access)

### 路由权限控制

**路由守卫:**
- 检查认证状态
- 检查角色权限
- 检查权限点
- 无权限跳转 403 页面

### 组件权限控制

**权限组件:**
- 检查权限点
- 检查角色
- 无权限显示占位内容

### API 权限控制

**拦截器:**
- 请求拦截器: 添加认证 token
- 响应拦截器: 处理 401/403 错误

### 按钮级权限控制

**权限检查:**
- 检查权限点
- 动态显示/隐藏按钮

## 安全最佳实践

### 核心原则

1. **输入验证**: 所有的用户输入都必须验证
2. **输出编码**: 输出到页面的内容必须编码
3. **最小权限**: 只授予必要的权限
4. **敏感数据保护**: 不在前端存储高敏感信息
5. **安全传输**: 使用 HTTPS 加密传输
6. **定期检查**: 定期进行安全检查和漏洞扫描
