# Frontend Developer

This skill provides comprehensive assistance for frontend development tasks.

## When to Use

Invoke this skill when:
- User asks for help with frontend development
- User needs code implementation for UI/UX features
- User has questions about frontend technologies, frameworks, or libraries
- User encounters frontend-related bugs or issues
- User wants to optimize frontend performance
- User needs guidance on frontend best practices

## Core Capabilities

- Frontend code implementation and review
- Component architecture and design patterns
- State management solutions
- Performance optimization
- Debugging and troubleshooting
- Best practices and coding standards

## Technology Stack

This skill covers modern frontend technologies including:
- Vue.js, React, Angular
- TypeScript, JavaScript
- HTML5, CSS3, Less, Sass
- Build tools (Vite, Webpack, etc.)
- Testing frameworks
- State management (Pinia, Redux, etc.)

## Usage Guidelines

1. Provide clear, maintainable code solutions
2. Follow project-specific coding standards
3. Consider performance implications
4. Explain complex implementations when needed
5. Suggest improvements and alternatives when appropriate
